# 封面插画规范（所有封面必须遵守，保证 18 张像同一套书）

站点是 2026 海豹杯科幻文学大赛获奖作品集，视觉方向是**孔版印刷（Risograph）套印**。每张封面像一张用 2–3 种专色油墨印出来的科幻小说封面：扁平的几何形、半调网点、轻微套印错位、纸张颗粒。

## 技术约束
- 文件：`art/covers/<id>.svg`，`viewBox="0 0 600 800"`（3:4），不写 width/height 属性。
- 纯手写 SVG：不得有 `<text>`、`<image>`、外部引用、`<script>`、`<foreignObject>`；文字（标题）由网页 HTML 负责，封面里不出现任何文字或字母。
- 单文件 ≤ 25 KB（压缩前）。路径坐标保留整数或 1 位小数。
- id 唯一：所有 `id` 加作品前缀（如 `zhuan-rengong-dots`），因为多张 SVG 可能内联在同一页面。
- 必须带 `<title>`（一句中文描述画面，作为无障碍替代文本），并在 `art/covers/<id>.txt` 写同一句描述。

## 色彩（只能用这些，不得出现其他颜色）
- 纸：`#EEEFEA`（第一层整幅矩形底）
- 粉 `#FF48B0`：代表人类评委奖
- 蓝 `#0078BF`：代表 AI评委奖
- 黄 `#FFE800`：代表鱼竿奖
- 墨 `#1E2140`：细线与小面积点睛，总面积 ≤ 10%
油墨层用 `<g style="mix-blend-mode:multiply">` 叠印，粉蓝重叠处自然得到紫色。允许用 `opacity` 调深浅（0.35–1），但不得用渐变色以外的新颜色；渐变只能在同一油墨的不同透明度之间。

## 油墨分配（编码获奖信息，必须遵守）
- 两个评审团都获奖 → 粉 + 蓝为主，二者必须有明显叠印区
- 只获人类评委奖 → 粉为主（+ 墨），蓝最多作极少量点缀
- 只获 AI评委奖 → 蓝为主（+ 墨），粉最多作极少量点缀
- 获鱼竿奖 → 额外加入黄色作为明显的第二/第三油墨
- 未获鱼竿奖的作品不使用黄色

## 质感（每张都要有，统一参数）
- 半调网点：用 `<pattern>` 做圆点网（点径 2–4，间距 6–10），用于至少一个大色块的填充或阴影。
- 套印错位：粉层与蓝层之间整体错开 3–5 px（`transform="translate(4 -3)"` 之类）。
- 纸张颗粒：一个 `<filter>`：`feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="2"` → `feColorMatrix` 转成低透明度的墨色噪点，叠在最上层，opacity ≈ 0.12。
- 构图留白：画面四周至少 36px 安全边距，底部 1/4 尽量安静（网页可能叠放标题）。

## 画面
每部作品一个**强符号**（不是剧情插画）：从小说的核心设定提炼出一个科幻意象，用大块几何形表达。参考深度：读作品的开头、目录和作者声明，抓住它的"新奇点"（novum）。避免：机器人脸、发光大脑、地球+星空这种空泛意象；避免卡通人物脸部细节。人物如需出现，用剪影或局部（手、背影）。
可借用的科幻图形语言：轨道线、星图坐标、信号波形、示波器网格、等高线、电路走线、条形码/数据块、透视网格、天体、半调月面。

## 验证
画完用 `qlmanage -t -s 600 -o <scratchpad目录> art/covers/<id>.svg` 渲染成 PNG（或 `magick`），用 Read 工具查看图片，确认：颜色正确、叠印可见、没有被裁切、整体像同一套书。至少自我修正一轮。用 `python3 -I -c "import xml.etree.ElementTree as E;E.parse('art/covers/<id>.svg')"` 检查 XML 合法。
